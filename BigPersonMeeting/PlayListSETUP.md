# 把網頁連到你的 Google 試算表

網頁是純前端的靜態檔案，沒辦法直接登入你的 Google 帳號讀寫試算表。做法是在
**試算表本身**建立一個 Google Apps Script，部署成一個網址（Web App）。網頁呼叫
這個網址就能讀取歌曲、寫入點歌記錄，不需要任何 API 金鑰。

你的試算表：
`https://docs.google.com/spreadsheets/d/11jJNNMv2PeYy7nEMqA2efXb5_CTYjESJWTmFLgjioSs/edit`

底下剛好已經有 4 個分頁對應網頁的 4 個分類：

- 女聲國語
- 男聲國語
- 男聲台語
- 女聲台語

每個分頁欄位都是 **歌手 / 歌曲 / 備註**，不需要新增任何欄位或分頁。

## 步驟 1：貼上 Apps Script 程式碼

1. 打開試算表 →「擴充功能」→「Apps Script」。
2. 刪掉預設內容，貼上 **Code.gs** 全部內容，存檔。

## 步驟 2（選用）：先建立 Requests 分頁

在函式下拉選單選 **setup**，按執行（▶），第一次會跳授權視窗，選帳號 →「進階」→
「前往...(不安全)」→ 允許（這是 Google 對自己寫的腳本的標準警告）。這步只是先建
好「Requests」分頁；就算跳過，第一次有人送出點歌時也會自動建立。

## 步驟 3：部署成 Web App

1. 右上角「部署」→「新增部署作業」→ 類型選「網頁應用程式」。
2. 「執行身份」選 **我**；「誰可以存取」選 **任何人**。
3. 部署 → 再授權一次 → 複製網址（長得像 `https://script.google.com/macros/s/.../exec`）。

## 步驟 4：把網址貼進網頁

`index.html` 最上面：

```js
const SCRIPT_URL = '你的網址';
```

目前 index.html 已經貼好你提供的網址，不用再改。

## 資料怎麼流動

- **讀取**：網頁開啟時呼叫 `?action=songs`，Apps Script 依序讀 女聲國語/男聲國語/
  男聲台語/女聲台語 這 4 個分頁的歌手/歌曲/備註，合併回傳 JSON，網頁依分頁畫出
  4 個分類頁籤，每個頁籤內再依歌手分組成一頁一頁的歌本、附上篩選晶片。
- **寫入**：使用者勾選歌曲、按「送出點歌」，網頁把勾選清單（含所屬分類）POST 給
  Apps Script，寫進「Requests」分頁（欄位：Timestamp / Tab / Category / Singer /
  Song / Note）。

## 之後你在試算表加/刪歌手、歌曲

直接在對應的分頁（女聲國語 / 男聲國語 / 男聲台語 / 女聲台語）新增或刪除列即可，
重新整理網頁就會同步，不需要改任何程式碼。

## 之後改了程式碼要怎麼更新？

回 Apps Script 編輯器貼上新版存檔 →「部署」→「管理部署作業」→ 針對現有部署按
「編輯」→ 版本選「新版本」→ 部署。網址不會變，不用重新貼到網頁裡。
